支援限制、光碟注意事項與隱私說明

主機：不依主機名稱限制，FC、SFC、GB、GBA、MD、N64、NDS 等一般 ROM，及 PS1、PS2、PSP、Saturn、Dreamcast、GameCube、Wii 等未壓縮 ISO／BIN 均可依相符補丁嘗試；可套用不等於可以修復壓縮或特殊封裝。

格式：BPS、UPS 會驗證補丁及輸出 CRC32；PPF2／PPF3 可依原始區塊驗證；IPS／IPS32／PPF1 無內建原始 CRC32，請搭配補丁發布者指定版本。BPS 目標需暫存（上限 512 MiB）。VCDIFF 小型檔案可在記憶體模式下載，大型檔案可分段直存，但直存模式尚未支援 VCD_TARGET 跨視窗回讀。XDELTA 目前支援採標準碼表、未採用次級壓縮的 VCDIFF；含 LZMA/DJW/自訂碼表的版本會明確拒絕，不會假裝成功。

儲存目錄：Chrome／Edge 使用原生檔案選擇器載入 ROM 後，可把原檔所在資料夾作為另存視窗的起始位置；使用拖曳時會嘗試取得位置，若瀏覽器未提供檔案控制代碼，請改用選檔或自選輸出資料夾。瀏覽器基於安全性不提供完整磁碟路徑，且儲存前必須由使用者確認；其他瀏覽器可能只能使用預設下載資料夾。

大型檔案：IPS、IPS32、PPF、UPS 以及支援的 XDELTA 可分段處理，需 Chrome／Edge 提供 File System Access API；是否可完成仍取決於可用磁碟空間、瀏覽器與檔案實際結構。IPS 只能寫入前 16 MiB，IPS32 最高使用 32-bit 偏移；PPF3 支援 64-bit 偏移但受瀏覽器安全整數限制。

光碟：CUE 是索引，請對補丁指定的 BIN/ISO 操作。多音軌或多檔 BIN 不會自動整合；套用後保留原有 CUE 並確認檔名對應。CHD、CSO、RVZ、GCZ 等壓縮映像須先解壓還原，程式不會把它們冒充原始 ISO。

隱私：這份 HTML 的補丁處理 CSS、JavaScript 及工作執行緒完全內嵌。ROM、ISO、BIN、補丁內容與檔名都只留在本機；只在設定 Google Apps Script 計數服務後，傳送「ROM 或補丁」的匿名載入事件與隨機去重 ID，不傳送任何檔案資料。無網路仍可打補丁；計數會留在本機佇列，恢復連線後嘗試同步。
